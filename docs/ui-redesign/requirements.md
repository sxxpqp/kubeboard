# KubeBoard 产品需求

版本：2.0 · 2026-10-22 · 当前唯一产品需求基线

## 产品定位

面向单集群管理员与项目开发者的 Kubernetes 资源管理控制台。以 KubeSphere 3.4 的资源管理体验为主参照，完成巡检、配置、发布与排障闭环。现有错误设计允许直接替换，不要求保留其交互或代码结构。

范围覆盖当前全部资源：集群、项目、节点、工作负载、Pod、任务、定时任务、服务、路由、伸缩、网络策略、存储和配置。企业空间、多集群、多租户、应用商店、DevOps 与长期监控不纳入本轮；这些是产品裁剪，不属于已实现的等价能力。

## 用户任务

1. 巡检：从集群/项目概览识别异常，进入对应筛选列表和对象。
2. 发布：创建工作负载，查看副本与更新，修改配置，比较版本并回退。
3. 排障：工作负载 → Pod → 容器 → 日志/终端；工作负载事件与 Pod 事件分别查看。
4. 关联：服务找到后端，PVC 找到 PV 与使用 Pod，Pod 找到所属控制器和节点。
5. 配置：读写类型明确的表单，复杂配置用 YAML；编辑不可丢弃未知字段。

## 导航与路由

集群视图展示节点、项目、PV、存储类以及跨项目资源。项目视图锁定 Namespace，菜单仅展示项目范围资源。项目概览是独立页面，不用工作负载列表充当概览。

项目列表：`/projects/:namespace/pvcs` 等；集群列表：`/pvcs` 等。对象详情必须可直接访问并恢复正确范围，旧链接允许重定向，页面 namespace 不使用查询参数。后端 API 参数不受此限制。

## 全资源需求矩阵

| 资源 | 列表核心内容 | 详情资源状态 | 操作/关联 |
|---|---|---|---|
| Deployment | 名称、状态、镜像、副本、时间 | 副本、策略、Pod/容器、发布条件 | 伸缩、重启、镜像、日志、终端、回退 |
| StatefulSet | 名称、镜像、就绪、副本 | 服务名、更新策略、容器、存储模板 | 服务、Pod、PVC；伸缩、重启 |
| DaemonSet | 名称、期望/就绪节点 | 调度与更新策略、容器 | Pod；无副本伸缩入口 |
| Pod | 名称、状态、节点、IP、重启 | 容器、资源、卷、四项调度条件 | 所属工作负载、节点、日志、终端 |
| Job | 名称、完成度、开始/完成时间 | 完成数、并行度、重试、容器模板、条件 | 关联 Pod；日志从容器进入 |
| CronJob | 名称、表达式、暂停、最近执行 | 时区、并发策略、历史保留、任务模板 | 关联任务 |
| Service | 类型、IP、端口 | 端口映射、选择器、真实 Endpoints | 后端 Pod、已有连通性检查 |
| Ingress | 主机、入口地址、类型 | 路由规则、后端、TLS 引用 | 服务详情 |
| HPA | 目标、最小/最大/当前副本 | 指标目标、伸缩行为、条件 | 工作负载 |
| NetworkPolicy | 名称、项目、选择器 | 策略类型、入站、出站及规则 | 显示无规则与未配置的区别 |
| PVC | 状态、容量、访问模式、存储类 | 请求/实际容量、绑定 PV、使用者 | PV、存储类、使用 Pod |
| PV | 状态、容量、存储类 | 回收策略、卷模式、声明引用 | PVC；不能把 PV 当 PVC 解析 |
| StorageClass | provisioner、默认、回收策略 | 绑定模式、扩容能力、参数 | PVC/PV |
| ConfigMap | 名称、键数量、时间 | 配置键值、二进制键 | 元数据、YAML 编辑 |
| Secret | 名称、类型、键数量 | 类型、键列表、遮蔽值 | 不自动解码或展示明文 |
| ServiceAccount | 名称、项目、时间 | 自动挂载、镜像拉取凭据引用 | Secret 引用 |
| Node | 状态、角色、版本、容量 | 系统信息、容量/可分配、污点、条件 | Pod、已有不可调度操作 |
| Namespace | 名称、状态、时间 | 汇总、配额、项目资源入口 | 进入项目范围 |
| Event | 时间、类型、对象、原因、次数 | 对象与原因可读 | 进入对应对象 |

## 公共行为与验收

- 名称进入独立详情；列表必须支持名称搜索、状态筛选（适用时）、分页、刷新和总数。返回列表保留范围和筛选。
- 详情常驻摘要，资源状态优先，元数据单独展示。每类资源使用专属字段，不以整份 spec 或 YAML 代替内容设计。
- 创建工作负载依次配置基本信息、容器、存储、高级选项、确认；简单资源采用单页表单。
- 变更明确对象和影响，防止重复提交；失败保留输入并可重试。无权限、能力关闭、请求失败、无资源、无筛选结果分别处理。
- 指标只呈现实际可获得的数据；无历史存储不展示历史曲线。Secret 默认遮蔽；只有明确操作才进入敏感内容编辑。
- 发布历史显示实际保留记录，提供两个版本配置对比；不误把默认保留数作为强制截断。
- 未知、未配置、零值分别展示；conditions 按类型解释，不能将全部 False 统一当作失败。
